# Japan 3D World

Small Next.js + React Three Fiber prototype of a stylized Japanese street.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

### Controls
- WASD / arrow keys: move camera
- Drag: rotate camera
- Mouse wheel / pinch: zoom

This first version intentionally uses procedural geometry only, so there are no external 3D assets to download.
