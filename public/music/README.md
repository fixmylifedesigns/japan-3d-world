# Music

Each folder here is a playlist. Drop audio files in and they show up in the game's music player —
no code changes needed.

```
public/music/
  japan/      <- plays in Shibuya
  newyork/    <- plays in Times Square
```

- Supported: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav`, `.flac`, `.webm`. `.mp3` is the safest everywhere.
- The track name shown in the player comes from the file name: `03 - night_drive.mp3` shows as "night drive".
- Files are served as-is, so keep them small (a few MB each) — they download when the player starts.
- Adding a new place: make a folder here, then set `music: "<folder>"` on that city in `src/components/cities.ts`.

`index.json` is generated by `scripts/build-music.mjs` (it runs automatically before `npm run dev` and
`npm run build`). Run `npm run music` to refresh it by hand. Don't edit it directly.

Only add music you have the rights to use.
