# Background sound

Each folder here is the background sound (street ambience or music) for one place. Drop audio files in and they
play there — no code changes needed. It switches automatically as the player moves between places, loops, and
starts on the player's first click or key press (browsers don't allow sound before that).

```
public/music/
  japan/      <- Shibuya street
  newyork/    <- Times Square street
  konbini/    <- inside the 7-Eleven
  retro/      <- inside Retro Games
  gacha/      <- inside the Gachapon shop
  deli/       <- inside the deli
  pizza/      <- inside the pizza shop
  subway/     <- the Times Sq–42 St station
```

A place whose folder is empty is quiet, so street noise doesn't follow you indoors. A folder with one file loops it;
a folder with several plays them in order. The music button in the HUD pauses it (remembered), skips tracks and
sets the volume.

- Supported: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav`, `.flac`, `.webm`. `.mp3` is the safest everywhere.
- The track name shown in the player comes from the file name: `03 - night_drive.mp3` shows as "night drive".
- Files are served as-is, so keep them small (a few MB each) — they download when the player starts.
- Adding a new city: make a folder here, then set `music: "<folder>"` on that city in `src/components/cities.ts`.
  A new shop or indoor place just needs a folder named after its id.

`index.json` is generated by `scripts/build-music.mjs` (it runs automatically before `npm run dev` and
`npm run build`). Run `npm run music` to refresh it by hand. Don't edit it directly.

Only add music you have the rights to use.
